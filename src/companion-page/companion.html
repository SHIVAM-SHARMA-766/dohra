Dohra

Transcription companion

Transcripts are made on this computer by a small companion program running whisper.cpp. The browser starts it when needed; no audio leaves the machine. Installing it downloads about 550 MB, mostly the speech model.

Install

Run these in a terminal. They need the GitHub CLI signed in to an account with access to the Dohra repository. Afterwards, come back here and press Check again.

Good to know

  • The default medium model runs at about real time on a 6-core laptop CPU. During a class it works at low priority and catches up afterwards; expect the full transcript roughly 10–15 minutes after an hour-long class ends. install --model small is faster but less accurate, particularly for Hindi.
  • dohra-companion status shows what is installed and any unfinished work.
  • dohra-companion uninstall --purge removes it completely.
